# 🚀 Project Hail Mary : Breakout

> 소설 『프로젝트 헤일메리』를 모티브로 한 우주 테마 벽돌깨기 웹 게임
> 2학년 1학기 웹프로그래밍 4인 팀 프로젝트 (2026.05 ~ 2026.06)

<br>

## 🎮 게임 소개

태양 에너지를 먹고 증식하는 미생물 **아스트로파지**로부터 태양을 지키기 위해, 우주선 **헤일메리호**를 조종해 아스트로파지 블록을 파괴하는 게임입니다.

일반 벽돌깨기와 달리 **연료**가 생명이자 자원입니다. 공 발사, 공 놓치기, 스킬 사용에 모두 연료가 들고, 0이 되면 임무 실패입니다. 그래서 언제 스킬을 쓸지, 떨어지는 아이템을 받을지 피할지 계속 판단해야 합니다.

| 스테이지 | 이름 | 특징 |
| :---: | --- | --- |
| 1 | 태양이 죽어가고 있다 | 기본 블록, 튜토리얼 성격 |
| 2 | 타우 세티로, 로키와 함께 | 블록이 12초마다 증식, 로키 버프 등장 |
| 3 | 아스트로파지 파괴 | 고체력 블록, 7초마다 증식, 레이저 스킬 해금 |

**조작법**
- 마우스: 패들(헤일메리호) 이동 / 클릭: 공 발사
- `S`: 슬로우 스킬 · `R`: 레이저 스킬 (환경 설정에서 키 변경 가능)

## 🛠 내가 맡은 부분: 아이템 & 스킬 시스템

담당 파일: [`src/itemSkill.js`](./src/itemSkill.js)

### 1. 아이템 드롭 & 낙하
- 블록이 파괴될 때 확률적으로 아이템 생성
  - **연료 아이템** (20%): 획득 시 연료 +20
  - **우주 파편** (스테이지별 10% / 15% / 20%): 닿으면 연료 -15
- 스테이지가 올라갈수록 파편 확률을 높여 난이도를 조정하였습니다.
- 매 프레임 아이템을 낙하시키고 패들과의 충돌을 판정, 화면 밖으로 나간 아이템은 정리합니다.
- 아이템은 이미지 없이 Canvas로 직접 그렸습니다. 연료는 방사형 그라디언트로 빛나는 구슬, 파편은 불규칙한 다각형으로 표현했습니다.

### 2. 스킬

### 3. 쿨타임 UI

- 다른 팀원이 만든 연료 시스템, 시스템 로그와 연결해 스킬 사용 시 연료 차감과 로그 출력이 함께 일어나도록 했습니다.

## 🔥 트러블슈팅: 슬로우 해제 후 공 속도가 급증하는 문제

**문제**
처음에는 슬로우 시작 시 공 속도에 `0.5`를 곱하고, 4초 뒤 `2`를 곱해 되돌렸습니다. 그런데 테스트 중 슬로우가 끝나면 공이 원래보다 훨씬 빨라지는 현상이 생겼습니다.

**원인**
- 슬로우 중에 **아직 발사되지 않은 공**이나 **새로 생긴 공**에도 `×2`가 적용됐습니다.
- 슬로우 중에 공이 벽·블록에 부딪히면 물리 엔진이 속도를 다시 계산하기 때문에, "지금 속도 × 2"가 "원래 속도"와 같다는 보장이 없었습니다.

**해결**
- 발사된 공에만 스킬을 적용하고, 슬로우 직전의 원래 속도를 공마다 저장했습니다.
- 해제할 때는 **현재 방향은 유지한 채, 속도의 크기만 원래 값으로** 맞췄습니다.

```js
const speed = Math.hypot(b.vx, b.vy);                  // 현재 속도 크기
const originalSpeed = Math.hypot(b.originVx, b.originVy); // 슬로우 전 속도 크기
const ratio = originalSpeed / speed;

b.vx *= ratio;   // 방향은 그대로, 크기만 복구
b.vy *= ratio;
```

**배운 점**
상태를 "되돌리는" 코드는 그 사이에 다른 시스템이 같은 값을 바꿀 수 있다는 걸 전제로 짜야 한다는 걸 배웠습니다. 물리 담당 팀원과 같은 값을 공유하는 구조였기 때문에 더 중요했습니다.
→ 관련 커밋: [`7da6abd`](https://github.com/parkcoool/wp-project/commit/7da6abdaf27d3084f7a8f3f89b2d7b8649351cf3)

## 🤝 협업 방식
- 기능 단위로 파일을 나누고 `state.js`의 전역 상태(`GameState`)를 공유하는 구조로, 4명이 같은 파일을 동시에 고치는 충돌을 줄였습니다.
- 약 한 달간 79개의 커밋, `Feat` / `Fix` / `Design` / `Refactor` 커밋 컨벤션 사용
- 플레이 테스트를 반복하며 아이템 확률, 낙하 속도, 스킬 쿨타임을 여러 차례 함께 조정했습니다.

## 📝 회고 & 개선하고 싶은 점
- **매직 넘버 상수화**: 확률, 지속 시간, 레이저 너비 등을 `state.js`의 설정값으로 옮겨 밸런스 조정을 쉽게 만들고 싶습니다.
- **타이머 정리**: 스킬 사용 중 일시정지나 게임 오버가 되면 `setTimeout`이 그대로 도는 문제가 있어, 게임 루프 시간 기준으로 바꾸고 싶습니다.
- 커밋 메시지 컨벤션을 처음부터 팀과 맞추지 못한 점이 아쉬워, 다음 프로젝트에서는 시작 단계에서 규칙을 먼저 정하려고 합니다.
